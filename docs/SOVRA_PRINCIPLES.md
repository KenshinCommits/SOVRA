# SOVRA Non-Negotiable Principles

1. **Sovereignty**: Complete ownership and privacy of data.
2. **Local-first**: No mandatory cloud AI or external internet calls for core logic.
3. **Evidence before action**: Outputs must be backed by retrieved knowledge or verified tool execution.
4. **Human control**: Sensitive actions require explicit human approval via the Evidence Gate.
5. **Auditability**: Every action, tool call, and routing decision must be logged.
6. **Model agnosticism**: Code must not be tightly coupled to any specific model provider.
7. **Least privilege**: Tools have only the permissions they absolutely need.
8. **Sandbox execution**: Generated code executes in isolated Docker environments.
9. **Real deliverables**: SOVRA produces reports, code, and spreadsheets, not just chat bubbles.
10. **Honest capability claims**: Do not claim a model supports vision or tools without empirical verification.\n
