# UI Design System

## Design Philosophy
SECURE. INDUSTRIAL. TECHNICAL. TRUSTWORTHY. AUDITABLE.

## Actual Existing UI
- **Dashboard**: Features a "Sovereign Mode" indicator (green/pulsing) to assure users of offline operation.
- **Layout**: Dark-mode dominant with technical accents (gray/slate backgrounds, distinct borders).
- **Knowledge Base Panel**: Drag-and-drop zone for files, lists ingested files.
- **Models Test Panel**: Visualizes registered models as tags, provides a test console for routing.
- **Typography**: Clean sans-serif, using system fonts or standard Tailwind fonts.
- **Status Indicators**: Real-time server and database connectivity badges.

## Intended Future UI
- **Agent Workspace**: A split pane showing the agent's step-by-step progress on one side, and the current deliverable draft on the other.
- **Evidence Gate**: Clear modal/panel requiring explicit "Approve" or "Reject" with justification.
- **Audit Log**: A technical table view of all system actions.

## Accessibility
- High contrast text on dark backgrounds.
- Clear error states and disabled button visual cues.\n
